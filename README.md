# Halo PC (retail halo.exe 1.0.10.0621) reverse-engineering workspace

See PLAN.md for the phased multi-agent plan. This file is the operational reference.

## Layout
- bin/halo.exe            pristine copy of the game binary (never edit; game folder untouched; gitignored)
- ghidra/HaloCE.gpr       Ghidra project, a BUILD ARTIFACT regenerated from the text files below (gitignored)
- symbols/                source of truth for names
    - opensauce.txt        parsed OpenSauce 1.10 constants (Custom Edition addresses; see caveat)
    - chimera.txt          Chimera signatures resolved against THIS binary (hook-site hints, sig__ prefix)
    - chimera_sigs.json    raw patterns
    - ghidra_entries_fresh.txt  function entries from the untouched auto-analysis (used to validate CE addresses)
    - functions.txt        MERGED, what ApplySymbols applies (generated by tools/merge_symbols.py)
    - hints.txt            unapplied hints for agents (OpenSauce globals)
    - candidates_cea.json  7324 function names + string literals from the Halo CE Anniversary prototype source (names only)
    - candidates_xbox.json 323 confirmed Xbox declarations from halo-re/halo kb.json
    - agent_*.txt / user*.txt  outputs of later phases / manual edits (highest precedence)
- types/tags.h            655 tag structs/enums generated from invader definitions (tools/gen_tag_header.py)
- modules.json            function address -> {module, confidence, evidence} (Phase 1 output)
- scripts/                Ghidra Java scripts: ApplySymbols, ExportMeta, ExportDecompiledC
- tools/                  Python converters and the context-pack generator
- out/                    exports: functions.json, functions.csv, halo_decompiled.c, slices/, phase1/ (gitignored except JSON)
- vendor/                 shallow clones of OpenSauce, chimera, invader, halo-re, halocea (gitignored)

## Binary facts
- Retail Halo PC, NOT Custom Edition. PE32 x86, MSVC 7.1, linked 2014-05-13, no SafeDisc, not packed
- Image base 0x400000, entry 0x627f06, .text 0x401000-0x639596, 6592 functions after analysis
- Statically links D3DX9 (effect compiler), GameSpy SDK, CRT; Bink/ogg/vorbis are DLLs

## Caveat: Custom Edition addresses
OpenSauce (and most community offset lists) target haloce.exe. Same source and build day as this binary but the
layouts drift irregularly, so a CE address is only trusted here when it lands exactly on a retail function entry.
Chimera works by byte signature and was resolved against this file, so its hits are valid.

## Rebuild the Ghidra project from the text files
    set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-21.0.5.11-hotspot
    set MAXMEM=4G
    set G=C:\Users\Liam-\Downloads\ghidra_12.1.3_PUBLIC_20260817\ghidra_12.1.3_PUBLIC
    set R=C:\Users\Liam-\halo-re
    python tools\merge_symbols.py
    %G%\support\analyzeHeadless.bat %R%\ghidra HaloCE -import %R%\bin\halo.exe -overwrite ^
        -processor x86:LE:32:default -cspec windows -scriptPath %R%\scripts ^
        -preScript ApplySymbols.java %R% -postScript ExportMeta.java %R%\out -postScript ExportDecompiledC.java %R%\out
Use -process halo.exe instead of -import/-overwrite to apply incrementally to the existing program.

## Tools
    python tools\pack.py 0x4xxxxx [more addrs] [--out dir]   context pack for agents (meta + hints + decompiled C)
    python tools\seed_modules.py                               lib tagging + name-prefix seeds into modules.json
    python tools\make_slices.py 300                            Phase 1 inputs, out/slices/NN.md
    python tools\merge_phase1.py                               Phase 1 outputs -> modules.json, with a coverage report
    python tools\smooth_modules.py                             contiguity smoothing of lone cross-module functions
    python tools\mechanical_names.py                           zero-agent names from CEA strings + Chimera entry sigs
    python tools\make_batches.py 60 120                        Phase 2 inputs, out/phase2/<module>/NN.md + index.json
    python tools\merge_phase2.py                               out/phase2/results/*.json -> symbols/agent_phase2.txt, prototypes.txt, review_queue.txt

## Phase 2 session loop (5 agents per session)
1. Launch the naming workflow on up to 5 batch groups (see PLAN.md session log for what is done).
2. python tools\merge_phase2.py ; python tools\merge_symbols.py
3. Headless -process with -preScript ApplySymbols.java and the two export post-scripts (command above).
4. python tools\make_batches.py 60 120   (so the next batches see the new callee names)
