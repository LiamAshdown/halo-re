# Renames that CONTRADICT a pre-existing inherited name, with the evidence:
#   0x507610 / 0x507cc0 / 0x5097e0 were named antenna_* by phase 2. They never touch the
#   `antenna` widget in types/objects.h: all three resolve the object's Physics tag
#   (Object tag +0x8c) and iterate Physics.mass_points at stride 0x80, and the dispatch
#   in 0x5061c0 / 0x505350 reaches them for object_type == 1 (vehicle) under mask bit
#   0x400000. See out/phase4/physics_types_notes.md section 5.
#
# Corrections made by the phase-4 integration pass, against out/phase4/physics_functions.md:
#   0x504f60 is the SEGMENT node test and 0x5050b0 the PILL node test, not the other way
#   round: 0x504f60's BSP callee is 0x502060 (collision_bsp_query_segment_init) and
#   0x5050b0's is 0x502730 (collision_bsp_query_pill_init).
#   0x505330 is a material-type table lookup (ModelCollisionGeometry materials, tag
#   offset 0x238, stride 0x48, field 0x24), not a marker-to-node-index mapping.
#   0x503d90's first stack parameter is the ModelCollisionGeometryBSP, not a material
#   type: 0x506440 passes structure_collision_bsp and 0x505200 passes the selected node
#   permutation record.
