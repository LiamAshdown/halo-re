# effects module (0x44c800..0x53fc80, 124 Ghidra functions) names established by the
# phase-4/5 C rewrite in src/effects/*.c; each name is justified in that file's header
# comment and in out/phase4/effects_types_notes.md. The confidence column is that file's
# own `name confidence` line, not a flat 0.8, matching symbols/agent_phase4_physics.txt.
#
# Renames that CONTRADICT a pre-existing inherited name, with the evidence. Ghidra's own
# auto-analysis had named a whole family of this module particle_system_*; they operate on
# the effe tag and the 0xfc byte effect_data record at 0x0087abdc, not on the pctl tag and
# the 0x158 byte particle_system_data record at 0x0087abd4, which is a different table with
# a different initializer. out/phase4/effects_types_notes.md carries the full table:
#   0x450630 particle_system_try_and_get        -> effect_try_and_get
#   0x450be0 particle_system_delete_450be0      -> effect_delete
#   0x451290 particle_system_property_random_value -> effect_property_random_value
#   0x451500 particle_system_new                -> effect_new
#   0x451a30 particle_system_update             -> effect_update
#   0x451f90 particle_system_spawn_particles    -> effect_spawn_particles
#   0x453f60 particle_system_delete_453f60      -> particle_system_delete (this one really is
#                                                 the pctl table; only the suffix is dropped)
#   0x453290 transition_function_evaluate       -> effect_distribution_function_evaluate. The
#            math module owns the real transition_function_evaluate at 0x4ccac0; this is the
#            effect distribution-function evaluator and the two were conflated.
#   0x44cb50 sig__contrail_update_sig           -> contrail_update (Chimera signature label)
#   0x44e2b0 sig__decal_table_sig               -> decals_update_fade (Chimera signature label;
#            the function is the per-frame fade driver over the whole decal table)
#
# Corrections made by the phase-4 integration pass, against the two rewriter passes:
#   0x44edc0 FUN_0044edc0 is decal_place and its first parameter is the Decal TAG index, not an
#            object index (raw 0x004502b4 `mov edx,[ebp+8]; mov [esi+0x2c],edx`, and [ebp+8] is
#            the same value 0x0044edee resolves tag data from). Phase 2 had guessed decal_new
#            for this address; decal_new is 0x44dd90.
#   0x451310 effect_random_velocity_vector's param_3/param_4 are OUTPUT pointers, not min/max
#            values: Ghidra writes *param_3 = *param_2 and reads param_3 back to build param_4,
#            and effect_spawn_particles 0x451f90 reads both back as 3-float vectors. min/max are
#            param_5/param_6. This resolved the signature conflict the first rewriter flagged.
#
# Thirteen of the module's 124 addresses are deliberately NOT named here because they belong to
# other modules (out/phase4/effects_types_notes.md): 0x44d820, 0x44d860, 0x44d8e0, 0x44d950,
# 0x44d9e0, 0x44da20, 0x44da60 (math / cseries), 0x44dad0, 0x44db30 (structures / bitmaps),
# 0x453330 (players), 0x4588e0 (math), 0x458990 (render) and 0x458b50 (structures). No file in
# src/ implements any of them yet.
