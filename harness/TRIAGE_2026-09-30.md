## Follow-up: likely harness artefacts, not rewrite bugs
`scenario_find_encounter_index_by_name` (0x432200), `encounter_definition_find_squad_index_by_name` (0x432260) and
`encounter_definition_find_platoon_index_by_name` (0x4322c0) are "crashed on every input". Their C matches the Ghidra
block exactly (stride, count/pointer offsets, `_strnicmp(..., 0x20)`), and the first argument is an implicit **ESI**
register parameter. The difftest most likely passes that pointer on the stack, or with random data, so only the
rewrite dereferences it. Check how `harness/build_difftest.py` feeds ESI for these three before touching the code; if it
is a harness gap, the same fix probably clears other "crashed on every input" entries with implicit register args
(e.g. `hs_compile_expression`).
